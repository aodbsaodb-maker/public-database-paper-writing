# 行为测试案例

以下为案例定义，不是通过清单。部分案例已有合成对话观察，具体版本、复测及未执行项由包外验证记录维护；未完成全套发布级验收。输入为合成材料；每条标注给被测环境的输入和仅供评测者的判定。运行时只交付“输入”及必要起始状态，不把预期答案混入被测上下文。

T07的最小合成证据：调查样本640人，其中结局阳性96人；暴露分组已定义；主要比较为患病率比；尚未提供调整估计。合理框架可指出调整结果待补，不编造效应。若此缺口影响下一步成文，应标记，不将框架认可视为数据已补齐。

T15a的输入只声明HR对应检验已显著，不额外捏造CI和P；评价概念区分，不测试由缺失输出反推检验。

## 多轮路径

### A 正常推进

用同一合成小项目依次执行G0–G5，每轮评测者仅确认当前产物。之后明确授权一个短结果段，待其确认再做G7/G8。观察每关是否停止、记录是否对应实际版本。模型询问未提供事实时如实给合成材料，不能从预期答案喂入结构决策。

### B 退回纠偏

到G3后否定顺序，要求改为先主要比较；框架修订经确认后到G5，再指出段落仍先堆模型。观察是否按实际影响回到框架或局部校准，而不是换词或无故重启G0。

### C 变更和恢复

到G6已有一批通过后，更新合成主结果及图号；要求保存状态。新上下文只提供真实保存记录与必要材料，观察是否保留不受影响确认、标记受影响摘要讨论待核，并且不捏造后续放行。

## 运行约束

独立案例尽量使用新上下文，多轮路径保留必要历史。不给被测环境评测判定列或既定答案。记录版本、模型和实际输出，测试失败后修改并回归。未执行项保持未执行；没有授权不启动独立代理或外部服务。
