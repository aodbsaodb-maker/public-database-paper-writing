# 公共数据库论文写作

版本：0.1.0-rc1，首个候选版本。

面向专业读者的观察性研究写作流程：先明确问题与证据，再讨论逐段框架，经作者审核后分批成文。

适用于公共数据库论文的框架、起草、修订、翻译、审阅和结果交接。支持单库与多库，不要求研究必须同时包含纵向结局或预测分析。

## 工作方式

```text
启动问答 → 提供资料 → 参考论文 → 逐段框架 → 写作契约
→ 试写校准 → 分批正文 → 整体核查 → 确认稿与交接
```

每关需要作者确认。补资料不等于放行，自审不代替作者审核。局部修改或单值核查按必要范围处理，不强制重走全流程。

## 主要机制

- 逻辑与表达认可、事实与证据核实分别记录。
- 从作者修改前后对照中学习具体论证偏好。
- 数据或主线变化后，只重开受影响的框架与稿件。
- 保持方法、结果、讨论、摘要、图表和补充材料一致。
- 按需检查陌生专业读者能否理解，以及适用报告规范是否有遗漏。

入口见[SKILL.md](SKILL.md)，简短演示见[合成示例](examples/synthetic-walkthrough.md)。

## 使用准备

在支持此类技能文件的运行环境中，按其当前规则加载整个目录，并确认入口已被读取。也可以在能够读取本地材料的环境中明确要求读取SKILL.md及其按需参考，进行不安装的试用。已验证的是显式读取下的部分合成任务，不是自动发现、安装或全平台兼容性，不提供未经验证的安装命令。

启动时可说：

> 我准备写一篇公共数据库观察性研究。先问启动问题，每关经我确认再继续。

可提供现有稿件、冻结结果与定义、最新图表、参考论文和个人写作偏好。材料可分批提供，私有项目记录留在自己的项目中，不写入本目录。

## 文件组织

- `SKILL.md`：入口及不可越关协议。
- `references/`：关卡、证据、框架、写作、核查及项目模板。
- `examples/`：完全合成的教学演示，不含真实研究结果。
- `tests/`：行为案例及验收规则，不作为日常写作时的答案模板。

## 范围与状态

本版本已完成格式检查及独立合成试用，覆盖逐关文字交互、框架回退、状态文件保存与新会话读取、小型稿件直接依赖同步及针对性复测。当前范围可供本地试用；多客户端兼容性、所有案例的多次独立重复及复杂格式稿件同步未完成，不作全平台或全面可靠性认证。检查范围由维护者本地记录保存，有限测试不保证所有任务稳定执行。

不提供统计分析正确性认证、临床决策建议或录用保证。关键数据、引文、结论及最终版本仍需作者亲自审核。报告规范用于检查报告遗漏，不用于补造方法。

运行不要求付费服务、执行脚本或固定的工具链；检索、文档渲染等任务取决于实际环境，缺少来源时明确记录。
